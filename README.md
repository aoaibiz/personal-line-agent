# Personal LINE Agent

**自分のLINEを、AIへのひと言で操作する。**

友だち・グループ・メッセージを扱う、自社開発の個人LINE向けMCPツールです。会話の取得、返信、メンション、グループ作成、表示名変更などをAIクライアントから操作できます。

**0.6.0候補：アルバム原本・添付の取得、OpenChatの検索・操作を追加しました。**

このブランチの版はMacの稼働環境へ反映済みです。既存のイベント受信・記憶・重複実行防止を保持しています。[機能対応表](docs/upgrade-20261105/COVERAGE.md)・[OpenChatの範囲](docs/upgrade-20261105/OPENCHAT.md)・[実接続の検証結果](docs/upgrade-20261105/VERIFICATION.md)。

[即時AI処理の範囲と運用](docs/EVENT-AGENT.md)。現在開いているローカルAIチャットへの即時pushとは別の機能です。写真・動画やサイト変更は作業票として引き継ぎ、通常の確認・案内だけを明示許可内で返信します。既存の受信画像機能も保持しています。 初回セットアップ後は、接続済みのAIクライアントへ指示して使います。返信のたびにターミナルや操作IDの転記を求める仕組みではありません。macOSでは既存版で送受信・メンション・グループ操作・表示名変更・画像と動画送信を確認しています。Windowsでは本人QR認証、正式MCPからのテキスト送信と読戻し、返信の常駐受信を実アカウントで確認しました。[Windows導入手順](docs/WINDOWS.md)を参照してください。

通常の接続確認、受信プロセスの再起動、バックエンド更新・切戻しは所有者のエージェントが担当します。**接続が正常なら再認証は不要です。** 接続不良時も保存済み接続と診断を先に調べ、LINE側が本人認証を必要とする場合だけ理由と操作場所を案内します。GitHubのリンクだけであらゆる障害や本人認証を自動解決できる保証はありません。

スマホだけでの強制再認証完了、新規利用者ごとのホスト設定は未検証です。初回QR認証の成功と、スマホだけでの再認証・全障害からの復旧は別です。未検証を成功扱いにはしません。[最終レビュー](docs/FINAL-REVIEW.md)・[検証状況](docs/STATUS.md)・[復旧手順](docs/OPERATIONS.md)を参照してください。

## できること

| 機能 | 内容 |
| --- | --- |
| 友だち・グループ | 一覧取得、件数集計、メンバー確認、表示名変更 |
| メッセージ | 取得できる履歴の保存・検索、新着受信、未読一覧 |
| 画像・添付・アルバム | 通常画像、履歴内の動画等、アルバム一覧・写真・原本を非公開保存。取得できる範囲と保存上限あり |
| OpenChat | 一覧・詳細・公開検索・対象ID照合・添付取得と、明示許可された13種類の操作 |
| プロフィール等 | 所有者プロフィール、背景、Note、通話リンク、LIFF共有。実機で確認した範囲は対応表に記載 |
| 送信 | テキスト、メンション、登録済みの画像・動画など |
| グループ操作 | 作成、名称変更、招待 |
| 人間関係の記憶 | 分類・要約・本人による訂正の保存 |
| 返信支援 | 所有者が許可した履歴を利用する分類・返信案の作成 |
| 実行管理 | 同一依頼の重複防止、状態確認、一時停止、制限の設定 |

この候補のバックエンドMCPツールは56個。固定入口は別に状態確認・現行ツール呼出しの2個を提供します。書込みの操作種別は51種類です。追加機能は既存の許可範囲を自動では広げません。実装の存在と実機検証済みの範囲は[検証状況](docs/STATUS.md)で区別しています。

## 使い方のイメージ

- 「友だち一覧を出して」
- 「このグループの最近の会話を確認して、返信案を作って」
- 「この内容で返信して」
- 「この2人とのグループを作って」
- 「この人の表示名を変更して」

通常操作は、接続済みのAIクライアントがMCPを呼び出します。人間にターミナル操作や操作IDの転記を求めないことを製品要件としています。

新規認証後の通常操作は所有者の設定した許可範囲に従います。OpenChatには通常グループと別の対象・招待先・作成許可を設けています。所有者が指定した禁止対象・禁止操作・期限などを優先します。再ログインで既存の制限を消しません。機能を使えることと、無人で全員へ返信を始めることは別です。

## 導入について

初回セットアップは利用者本人または導入担当エージェントが行えます。更新時に人間へMCP再読込みを要求しない固定入口は[運用手順](docs/OPERATIONS.md)を参照してください。[導入手順](docs/INTEGRATION.md)を参照してください。初期導入を含め、内部コマンドは権限のあるエージェントが担当し、人間にターミナル作業を求めません。本人に必要なQR確認は画面上で行います。

実機確認済み環境はmacOS / Python 3.12とWindows / Python 3.11 64bitです。パッケージの要件はPython 3.11以上です。Windowsでは資格情報マネージャーと、利用者のログイン後に起動する専用の受信タスクを使います。PC電源OFF中やOSログイン前の稼働、全AIクライアントとの接続は保証していません。スマホ利用には、利用するAIクライアント側でホストへの認証済み接続が必要です。

返信支援の外部モデルは任意機能です。会話を外部AIへ送る設定は所有者の明示許可が必要です。現行実装はCodex CLIと設定済みモデルを利用し、その利用資格・上限・費用は各アカウントに依存します。

## データと安全性

- アカウントごとに保存先を分離し、履歴・接続情報を暗号化して保存します。暗号鍵はOSキーチェーンで管理します。
- LINEから届く本文は未信頼データです。相手の文章は操作権限を与えません。
- 実行結果が不明な送信を自動で送り直しません。同じ依頼IDを維持して状態を確認します。
- 個人履歴、認証情報、実アカウントの検証ログ、開発者のGit履歴はこの公開リポジトリに含めません。

詳しくは[セキュリティ方針](SECURITY.md)をご覧ください。

## 取得範囲と対応範囲

取得APIの履歴は、スマホに残っている全履歴と同じではありません。0件の応答を「会話が存在しない」と扱いません。期限切れで上流から失われた添付の復元やGoogleカレンダー連携は含みません。OpenChatの履歴は取得可能なイベント範囲です。VOOMは公式の提供終了と所有者の指定により対象外。誕生日は本人の項目・公開設定の確認に限り、友だち一覧取得は含みません。バックアップ抽出・個別の分類レビューサイトはこのパッケージには含みません。

LINE公式の製品・公式APIではなく、LINE運営元との提携や承認を示すものではありません。接続先の仕様変更や利用制限で動作が変わる可能性があります。
